# TP React Native

Ce dépôt regroupe les 3 TP réalisés en cours ainsi que le projet global :

- **TP1-DrawerMenu** : TP menu latéral (Drawer Navigator) et onglets inférieurs (Bottom Tabs) avec icônes.
- **TP2-Login** : TP inscription et connexion avec validation des champs et base locale SQLite.
- **TP3-Produits** : TP catalogue de produits SQLite avec `FlatList`, recherche, filtres par catégorie et pagination.
- **TP-Global** : Projet ReactJS précédent (`React_FB`) converti en React Native avec base de données SQLite, intégrant la navigation Drawer/Tabs et le catalogue produits.
